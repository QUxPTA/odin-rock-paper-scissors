## Playing the Game

### Online

To play the game online, just head over to this [link](https://quxpta.github.io/odin-rock-paper-scissors/), and play away!

### Offline

If you would like to play the game offline

```
git clone https://github.com/QUxPTA/odin-rock-paper-scissors.git && cd ~/odin-rock-paper-scissors
```

Then, drop the HTML file into your browser of choice, or open using liveserver in your favorite IDE
